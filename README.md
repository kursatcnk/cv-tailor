# CV Tailor

CV'ni başvuracağın ilana göre yeniden yazan bir çalışma alanı. CV'yi yüklüyorsun, ilanı yapıştırıyorsun; ilanın istediklerini CV'ndeki deneyimlerle eşleştiriyor, eksik kalanları sana soruyor ve ilana göre düzenlenmiş CV'yi indirilebilir olarak geri veriyor. Her değişikliğin yanında nedeni yazıyor; amaç sadece CV'yi düzeltmek değil, iyi CV yazmayı öğretmek.

Uydurmuyor: CV'de olmayan bir deneyimi, rakamı ya da teknolojiyi eklemiyor. Yeni yazılan her cümle senin verdiğin bir bilgiye dayanıyor.

> Geliştirme aşamasında.

ASP.NET Core Web API + SQL Server arka uç, sade HTML/CSS/JavaScript arayüz.
